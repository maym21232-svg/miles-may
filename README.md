# 美股研究 PWA

面向 iPhone 的中文美股研究网页，可筛选公司、查看财务快照并记录自选与背调笔记。基于 [crible](https://github.com/maxgfr/crible) 的 MIT 开源代码二次开发，保留原项目许可证。

在线使用：[美股研究](https://maym21232-svg.github.io/miles-may/)。

## 数据边界

GitHub Pages 版本使用 crible 公开快照，并在 GitHub Actions 中生成美国交易所上市公司的静态数据。它不是实时行情或投资建议。页面标明快照生成、网站重建和多数股票的价格日期；公司页的参考报价仅在可直连 Yahoo 且时间戳较新时显示，不经公共代理，直连失败时仍可打开来源链接核对。SEC 面板在静态版只提供官方申报链接，不冒充已完成实时核验。自选和笔记仅保存在当前浏览器，不自动跨设备同步；可以在“自选”页导出本地 JSON 备份，再在另一设备导入。备份可能包含个人研究笔记，请妥善保存。

首页重点研究池目标 400 家（最低 300 家），按最近财报、基本质量和行业分散确定；长线名单仅从该池筛选。短线观察名单最多 75 家，按当天收盘价、流动性、20/60 日趋势和财报质量筛选；它与长线重点池是两套独立名单。虚拟仓新增买入只从短线名单产生，已有持仓仍独立检查卖出。名单会随数据变化，并非涨跌概率。全市场公司仍可搜索、打开详情和使用高级筛选；当前构建仍从上游下载全市场快照，缩小跟踪池**尚未减少上游下载量**。

## 每日模拟决策

首页短线区上方展示公开的规则模拟组合。它只在价格覆盖至少 95%、且多数美股收盘日期等于最近一个 NYSE 交易日时评估；缺数据或上游延迟时暂停，不会以过期价格产生新买卖。交易所日历识别常规休市和提前收盘，临时停市仍以价格覆盖校验为准。它不是由 AI 每天人工逐股研究，更不存在 100% 确定的交易。

模型最多持有 4 只股票，每只模拟投入不超过 2 万美元，并同时检查财报质量、流动性、20/60 日趋势和放量。收盘后的决定先记为待执行，只有交易所日历上的下一交易日开盘价到齐、该股票价格序列也与决策日连续，且买入开盘跳空不超过 3% 时才以开盘价加减 0.1% 模拟滑点记账；缺失下一交易日价格时，不会用更晚的开盘价补记。止损、止盈、趋势转弱和持有时间会触发模拟卖出。方法不计税费、分红和拆股，不能用作实际投资收益测算。

`paper/ledger.json` 保存公开的虚拟仓位、决定和模拟成交。每日 Actions 构建先读上一版账本，成功验证后才提交新账本，并将 `paper-portfolio.json` 发布到网页；同一行情日期重跑不会重复记账。

## 安装到 iPhone

部署完成后，在 iPhone Safari 打开仓库的 HTTPS Pages 地址，点“分享”再点“添加到主屏幕”。需要联网加载选股、图表和披露数据；离线时只显示连接提示，不显示可能过期的行情。

## 发布

公开仓库的 `main` 分支会触发 `.github/workflows/pages.yml`。首次部署需在仓库 Settings > Pages 中将构建来源设为 GitHub Actions。工作流会从 crible 的公开数据地址下载快照，验证后构建并发布；计划每天检查一次。失败时保留上一版已部署网站。

本地开发在 `ui/` 运行 `npm ci` 和 `npm run dev`。本地正式构建可运行 `npm run build`；若要模拟项目子路径，设置 `VITE_BASE=/仓库名/`。此仓库不包含本地数据文件、密钥或本机日志。
